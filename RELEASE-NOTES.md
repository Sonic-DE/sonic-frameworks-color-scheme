# Sonic Frameworks Color Scheme Release Notes

Sonic Frameworks Color Scheme lets SonicDE apps follow the light or dark color scheme you choose.

## Unreleased

- Behind the scenes: the see-through titlebar settings can now follow the window decoration, turning off with one that doesn't support them and back on with one that does, with automatic tests.

## 6.31.0.1 (2026-11-10)

- Apps now reliably follow your chosen color scheme in SonicDE sessions.
- New: one shared place for the see-through titlebar and toolbar settings and their per-app exceptions, so window decorations, app styles and modern apps all apply them the same way. Behind the scenes: the new `KToolsArea` class, with automatic tests.

## 6.31.0 (2026-10-20)

- Behind the scenes: version update.

## 6.30.0 (2026-09-12)

- Behind the scenes: version update.

## 6.29.0 (2026-08-07)

No SonicDE-specific changes in this release; it brings the package up to date with upstream.

## 6.28.0.1 (2026-08-01)

- New Silver Light and Silver Dark color schemes, from SonicDE's own Silver theme, are now the defaults in place of Breeze.
- Behind the scenes: restored the code formatting settings and added support for developers' code-navigation tools.
